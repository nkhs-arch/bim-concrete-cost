# BIM 混凝土成本動態估算系統

選手大樓專題：用 Autodesk Forma Takeoff 或 Revit 明細表算出結構混凝土體積，搭配政府公開的最新單價，自動估算混凝土與鋼筋成本。

🌐 **網站：** https://nkhs-arch.github.io/bim-concrete-cost/

## 運作方式

```
Forma Takeoff 算出體積（樓板、柱、梁）
   │  模型改版時匯出 Excel，覆蓋 data/quantities.xlsx
   ▼
scripts/build_data.py（GitHub Actions 每週一 08:00 自動執行）
   │  體積 × 最新單價
   │  最新單價 = 工程會基準價 × 主計總處物價指數調整
   ▼
data.json → index.html 網頁儀表板
```

## 單價來源（政府開放資料）

| 資料 | 提供機關 | 更新頻率 |
|---|---|---|
| [大宗資材之混凝土價格調查](https://data.gov.tw/dataset/6819)（北區各強度單價） | 行政院公共工程委員會 | 每月 |
| [營造工程物價指數](https://data.gov.tw/dataset/8246)「水泥及其製品類」 | 行政院主計總處 | 每月 |

最新單價 = 工程會基準價 × 最新月份指數 ÷ 基準價月份指數

## 碳排放（6D 永續）

| 資料 | 提供機關 | 更新頻率 |
|---|---|---|
| 《低碳（低蘊含碳）建築評估手冊》（LEBR）附錄一 ABRI 初級資材碳排資料庫（P-LCC, 2022） | 內政部建築研究所 | 隨手冊改版 |

碳排係數統一採用建研所 LEBR（A1～A4：原料開採、原料運輸、產品生產、成品運輸），放在 `data/carbon_lebr.json`（混凝土、鋼筋）與 `data/rates.json`（模板、紅磚、砂漿）：

| 項目 | 係數 | LEBR 品項 |
|---|---|---|
| 預拌混凝土 210 / 280 / 350 kgf/cm² | 327.75 / 369.88 / 433.45 kgCO₂e/m³ | 預拌混凝土 3000 / 4000 / 5000 psi |
| 鋼筋（含損耗搭接的採購量） | 1.15 kgCO₂e/kg | 鋼筋及鐵件 |
| 模板 | 1.00 kgCO₂e/m² | 木模板（1.5cm） |
| 紅磚 | 0.45 kgCO₂e/塊 | 紅磚（20*9.5*5cm） |
| 1:3 水泥砂漿 | 452.5 kgCO₂e/m³ | 1:3 水泥砂漿粉刷 2cm 厚 9.05 kgCO₂e/m² 換算 |

245、315 kgf 用前後兩級內插。手冊改版時只要改這兩個檔。設環境變數 `CARBON_SOURCE=moenv` 可改回環境部「碳足跡排放係數」開放資料（共用金鑰每天 5000 次，可用 GitHub Secret `MOENV_API_KEY` 改用自己的金鑰）。尚未含施工機具與運輸（A5 之後）。

## 鋼筋重量與成本（練習假設）

鋼筋重量 = 各類型構件體積 × 鋼筋比（kg/m³）× (1 + 損耗率)

- **鋼筋比**寫在 `data/rebar.json`，依「類別＋類型」對照（例如梁 `45X75`、樓板 `30cm`）。數字來自練習配筋檔 S-0002，**是練習假設，不是正式結構設計**。體積檔需要有「類型」欄；對不到鋼筋比的類型會在日誌出現 `WARN`，該列以 0 計。
- **損耗＋搭接** 10%：業界 #5 以下約 5%、#6 以上依號數增加；模型沒有畫搭接與加密區，所以一併算進來。
- **單價**：

| 資料 | 提供機關 | 更新頻率 |
|---|---|---|
| [大宗資材之鋼筋價格調查](https://data.gov.tw/dataset/6820)（北區 SD420W，元/T） | 行政院公共工程委員會 | 每月 |
| [營造工程物價指數](https://data.gov.tw/dataset/8246)「金屬製品類」 | 行政院主計總處 | 每月 |

鋼筋單價 = 工程會基準價 × 最新月份金屬製品類指數 ÷ 基準價月份指數。同規格有多種直徑時取最細的（目前是 SD420W D32mm）。工程會調查沒有 Revit 配筋用的 #4、#6、#8（D13、D19、D25），以最接近的品項估算；依工程會資料，各號數價差約 2%。工程會與快取都沒有資料時，才改用 `rebar.json` 的 `fallback_price`，網頁會標示「參考市場行情，非政府資料」。鋼筋只算目前模型（舊版本的體積檔沒有類型資料）。

> 工程會網站無法從 GitHub 的海外主機連線，所以自動更新時沿用 `data/price_cache.json` 裡的混凝土與鋼筋基準價，只更新物價指數。要更新基準價時，在自己電腦執行一次 `python scripts/build_data.py` 再上傳即可。

## 常見操作

### 模型改版了
1. Revit 結構明細表（計量類型、樓層、類型、個數、體積）存成 `data/quantities.csv`；或 Forma Takeoff 匯出 Excel 改名為 `data/quantities.xlsx`（兩個都在時先讀 xlsx，換格式時記得刪掉另一個）
2. 有新的構件類型時，在 `data/rebar.json` 補上它的鋼筋比
3. 修改 `data/model_info.json` 的 `note`（例如「第二版」）
4. 上傳後會自動重算並建立新版本（V2、V3…）

### 在網頁上直接試算新的體積檔
網站上方「放入新的體積檔」可以拖入 Forma Takeoff 匯出的 Excel 或 Revit 明細表 CSV，瀏覽器會用最新單價重算整頁（成本、鋼筋、碳排、12 個月走勢），只有自己看得到，重新整理就還原。要存成正式版本時按「下載 quantities.csv」，上傳到 GitHub 的 `data/` 覆蓋同名檔案（有 `quantities.xlsx` 要刪掉）。網頁的讀檔規則寫在 `index.html`，跟 `scripts/build_data.py` 一樣，改其中一邊時另一邊也要改。

### 欄位與類型對照（參數映射）
每個專案匯出的 Excel 欄位名稱、類型名稱可能不同。網站上傳時會：
1. 自動找標題列與欄位（類別、體積、類型、個數、樓層、材質）；沒有類別欄時從表名、工作表名或檔名判斷
2. 從類型名稱讀出尺寸，對照 `data/rebar.json` 的鋼筋比（`B1-450x750`、`450×750mm` → `45X75`；`S1 150mm` → `15cm`）
3. 有對不到的欄位或類型時跳出「欄位與類型對照」畫面，黃色的要確認；可以選最接近的類型，或自填鋼筋比（kg/m³，填 0 表示不算鋼筋）

可以一次選多個檔案（例如 Revit 的結構柱、結構梁、樓板明細表 CSV），會合併成同一個版本。

對照會存在該專案（`data/projects.json` 的 `mapping`；選手大樓存在自己的瀏覽器），下次上傳自動套用。上傳後按「調整欄位對照」可以重新修改。下載的 quantities.csv 已經是對照後的標準格式（類別、類型都換成網站認得的名稱），`build_data.py` 可直接讀；自填的鋼筋比只存在專案裡，要正式使用請補進 `rebar.json`。

### 計算成果與分區
儀表板上方「計算成果與分區」可以勾選要算的成果（混凝土、鋼筋、碳排放），並選擇分組：整棟、依樓層、依構件類別、樓層＋構件。樓層取自體積檔的「樓層／位置」欄，沒有的列在「未分區」。選手大樓的分區讀 `data/quantities.csv` 的逐列明細。勾選與分組記在自己的瀏覽器。模板與磚（含耗材）在下一階段加入。

### 模板與磚（含耗材）
在「計算成果與分區」勾選「模板」「磚（含耗材）」即可計算，用量與單價寫在 `data/rates.json`（**練習假設，參考市場行情，非政府資料**，正式使用請換成工程會或公共工程價格資料庫的單價）。

- **模板面積**：Revit 的結構柱、結構構架沒有面積參數，所以由類型尺寸推算
  - 梁：長度 ×（底寬 ＋ 2 × (梁深 − 板厚)），長度 = 體積 ÷ 斷面（有長度欄就直接用）；板厚預設 15 cm
  - 柱：周長 × 高度，高度 = 體積 ÷ 斷面（有長度欄就直接用；只有長度沒尺寸時當方柱）
  - 樓板：底面積（有面積欄就用，否則體積 ÷ 板厚）
  - RC 牆：兩面面積（有面積欄就 × 2，否則 2 × 體積 ÷ 牆厚）
  - 都沒有時用經驗值（m²/m³）估算，網頁會註明
- **磚牆**：類別名稱含「磚」的構件（例如 Takeoff「磚牆-面積」），依面積 × 每 m² 用磚數與砌磚砂漿（1/2B 64 塊、0.027 m³；1B 128 塊、0.06 m³）＋ 損耗（不含砌磚工資；要算工資時在 `rates.json` 的 `labor_per_m2` 填每 m² 工資）；類型讀得出牆厚 ≥ 20 cm 算 1B，否則 1/2B
- **單價更新**：工程會大宗資材價格調查只有砂石、混凝土、鋼筋、H 型鋼、瀝青，沒有模板與紅磚，所以用 `rates.json` 的基準價（`price`／`brick_price` 與 `base_period`）× 主計總處營造工程物價指數個別項目「普通模板」「瓦片及紅磚」（最新月 ÷ 基準月）每月自動調整；指數檔沒有個別項目時用中分類「木材及其製品類」「磚瓦瓷類」
- 碳排目前還沒有含模板與磚

### 設定混凝土強度
Takeoff 匯出檔沒有強度資料，預設全部用 280 kgf/cm²。要指定時修改 `data/model_info.json`：

```json
"grades": { "columns": "350", "beams": "280", "floors": "280" }
```

### 寫更新日誌
網站功能或資料有變動時，在 `data/changelog.json` 最上面加一筆（日期＋項目），`type` 可用「新功能」「修正」「資料」「其他」。上傳後網站會自動更新。

### 手動重新估算
GitHub → **Actions** → **BIM 混凝土成本自動估算** → **Run workflow**

### 產生離線版 / PDF
```bash
python scripts/export_offline.py
```
會產生可直接雙擊開啟的 `BIM混凝土成本儀表板_離線版_<日期>.html`。

## 檔案說明

| 路徑 | 說明 |
|---|---|
| `index.html` | 網頁儀表板 |
| `data.json` | 計算結果（自動產生，不要手動改） |
| `data/quantities.csv` | 結構體積（Revit 明細表：計量類型、樓層、類型、個數、體積），也可改放 Forma Takeoff 匯出的 `quantities.xlsx`（兩個都在時先讀 xlsx） |
| `data/rebar.json` | 鋼筋比、損耗率、鋼筋規格（練習假設） |
| `data/model_info.json` | 模型名稱、版本備註、工地區域、混凝土強度 |
| `data/changelog.json` | 網站更新日誌（手動維護） |
| `data/versions.json` | 各版本體積紀錄（自動維護） |
| `data/price_cache.json` | 最近一次下載的單價資料（自動維護） |
| `data/carbon_cache.json` | 最近一次下載的碳排係數（自動維護） |
| `scripts/build_data.py` | 主程式：讀體積、抓單價、算成本 |
| `scripts/export_offline.py` | 匯出離線版 HTML |
| `scripts/certs/` | 補上政府網站缺少的中繼憑證。網站換憑證時程式會自動下載新的中繼憑證存成 `auto_*.pem`，不用手動處理 |
| `.github/workflows/bim_auto_cost.yml` | 自動排程設定 |
