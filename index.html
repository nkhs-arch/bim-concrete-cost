輸入 GitHub 權杖才能存專案

專案會存到 GitHub repo，所以需要一個有寫入權限的權杖。每台電腦只要輸入一次，會記在這台電腦的瀏覽器裡。

  1. 打開 GitHub 建立權杖頁面（Fine-grained token）
  2. Resource owner 選 nkhs-arch，Repository access 選 Only select repositories → bim-concrete-cost
  3. Permissions → Repository permissions → Contents 選 Read and write
  4. 按 Generate token，把 github_pat_ 開頭的那串貼到下面

權杖等於密碼，不要貼在公用電腦，也不要傳給別人。

上傳到 GitHub 存成新版本

要讓大家都看到：按「下載 quantities.csv」，再到 GitHub 的 data 資料夾上傳覆蓋同名檔案（data 裡如果有 quantities.xlsx 要刪掉），約 1 分鐘後網站會自動建立新版本。
